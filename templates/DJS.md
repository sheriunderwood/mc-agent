# DJs

Second Life DJs the avatar knows about. The agent reads this list at startup.
It only names DJs listed here, and only shares stream URLs listed here.

For each DJ, record:

- **Name**: the SL account name exactly as the grid gives it (display name in brackets if different)
- **Profile**: the profile link, `secondlife:///app/agent/<uuid>/about`, or the UUID from `find_person`/`profile`
- **Group**: the DJ's fan or update group, with its UUID if known
- **Stream URL**: the music stream they broadcast on
- **Plays at**: clubs, which can be cross-referenced with CLUBS.md
- **Genres**
- **Heard about from**
