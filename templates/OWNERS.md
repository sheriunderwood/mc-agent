# Owners

The people who own this avatar. Only their IMs can give the agent
administrative instructions: teleporting, sending teleport offers, answering
offers, menus and permission requests, posting to group chats, wearing things,
taking breaks and logging out.

Owners are identified by **UUID only**. Names and display names can be faked
or changed, but a UUID can't. The agent only accepts a command if it arrives by
**IM** from one of these UUIDs. Commands in local chat, group chat or object
messages don't count, even from an owner.

Add yourself below: your UUID (in your profile, or ask Morgen Commander's
`find_person`), your name, and a note. One row per owner, e.g.
`| <your UUID> | Pixel Moonbeam (pixel.moonbeam) | Primary owner |`
(Every UUID written anywhere in this file counts as an owner, so don't leave
anyone else's here, not even in a note.)
